# IELTS Pilot 路线图

## v0.1 基础练习闭环

- [x] 原创阅读文章与多题型渲染
- [x] 专项练习、倒计时、自动保存和本地评分
- [x] 结果页、答案解析和原文定位

## v0.2 完整模考与学习统计

- [x] 3 篇、40 题、60 分钟完整模考
- [x] 题库检索、筛选、备份与恢复
- [x] 趋势、题型正确率和历史成绩

## v0.3 Windows 桌面交付

- [x] Tauri 2 桌面壳与环境识别
- [x] NSIS 当前用户安装配置
- [x] Windows Release 构建工作流
- [x] 设置页与关于页中的版本、平台、来源说明

## v0.4 深度阅读工作流

- [x] 纸张、护眼、夜间主题及字号、行距、阅读宽度
- [x] 原文高亮、三色标记和本地笔记
- [x] 专项练习暂停、离开确认和键盘快捷键
- [x] 错题筛选、标记掌握和强化练习
- [x] 文章与题目收藏
- [x] 结果报告打印或导出 PDF

## v0.5 本地题库系统

- [x] 内容包 v2、旧版迁移和严格字段校验
- [x] 安装前预览、SHA-256 摘要、升级、冲突检测和卸载
- [x] 完整本地题库编辑器与草稿恢复
- [x] 示例内容包和格式文档
- [x] 内置原创题库扩充至 5 篇、54 题
- [x] 浏览器、移动端与桌面端自动化验证

## v0.6 安全发布与更新

- [x] Tauri updater 签名验证与应用内更新中心
- [x] GitHub Releases `latest.json` 和 updater 产物流水线
- [x] 普通构建与签名发布构建分离
- [x] 可选 Windows Authenticode 证书导入
