# IELTS Pilot v0.9.5 产品功能说明书

版本：0.9.5

适用平台：浏览器、Windows 10/11 x64

定位：本地优先的 IELTS 阅读、写作与学习行动工作台

## 1. 本版目标

v0.9.5 将悬浮助手从“给一段建议”升级为可验证、可执行、可复盘的学习驾驶舱。助手只读取应用已经计算出的有界学习快照，不直接读取浏览器存储，也不把整篇作文或 API Key 放进模型消息。

## 2. 三种助手视图

### 2.1 诊断

- 汇总阅读练习次数、平均/最佳练习 Band、专注时长、近期趋势、可靠薄弱题型和待巩固错题。
- 汇总最近五份写作报告的最新 Band、四维均值、相邻报告变化、重复优先项和证据数量。
- “样本不足”会明确标注，不用确定性语言承诺提分。
- 证据链可展开查看证据名称、数值、样本数和可信度。

### 2.2 计划

- 自动生成“今天”和“本周”行动，包含预计时长、原因和本地入口。
- 行动可直接进入匹配题型最多的练习、带题型参数的错题本或最近写作报告。
- 完成状态和计划保存在本机 `localStorage`；重新生成时保留仍然对应的已完成行动。
- 阅读行动记录创建时的题型正确率基线，只使用行动创建后的新作答衡量结果；少于 5 题时显示样本不足。

### 2.3 对话

- AI 必须返回 `schemaVersion: 1` 的结构化结论、事实、推断和最多三条行动。
- 所有事实与推断只能引用本机生成的稳定证据 ID；未知证据、外部 URL、越权字段和不受支持的高可信结论会被拒绝。
- 如果模型输出未通过校验，界面使用本地确定性建议并明确提示回退，不渲染未经校验的模型文本。
- 支持停止、失败重试、回答重生成、复制、单条删除、清空、新建对话、切换历史和删除对话。
- 最多保存 12 个对话、每个 40 条消息；旧版单对话自动迁移。

## 3. AI 配置与隐私

浏览器版必须通过同源本机网关调用，API Key 只在网关进程内存中使用。Windows 桌面版通过 Tauri Rust HTTPS 命令调用，API Key 使用当前 Windows 用户的 DPAPI 加密后存放在应用数据目录。设置页只把 Endpoint 和模型名写入浏览器存储，并拒绝包含 URL 用户名或密码的地址。

用户输入会在发送和保存前检查常见密钥特征；疑似凭据不会保存也不会出站。学习快照不含作文原文和写作证据原句。对话与计划默认不参与加密同步。

## 4. 评分与证据边界

阅读得分仍由本地 `reading-v2` 规则计算；写作 Band 仍由 `writing-v1` 四维结构化评估校验后由程序复算。助手不创造新的官方分数，只引用这些已验证结果和统计聚合。所有 Band 均为练习辅助估算，不是 IELTS 官方成绩。

## 5. 演示走查

在“设置 → 演示数据”安装固定演示档案后，可看到三次阅读尝试、两份写作报告、错题、收藏、批注和写作趋势。打开右下角 IELTS Pilot 悬浮球：

1. 在“诊断”展开证据链，核对样本数与可信度。
2. 在“计划”完成一条今日行动，再切换到本周计划。
3. 在“对话”提出“我现在最应该练什么？”，核对结构化回答与本地行动链接。
4. 新建第二个对话、切换历史、复制或删除消息。

## 6. 安装与升级

从 GitHub Release 下载 `IELTS.Pilot_0.9.5_x64-setup.exe` 后直接运行。安装器按当前用户安装；从旧版覆盖安装会保留当前用户的练习、报告、计划和设置。v0.9.2 及以上可通过“更新”页面检查签名版本。
