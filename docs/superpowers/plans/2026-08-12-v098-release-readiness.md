# IELTS Pilot v0.9.8 发布就绪实施计划

**目标：** 交付可换机、可排障、可验证升级的 v0.9.8 Windows 版本。

**架构：** 各存储仓库继续负责自己的版本迁移和输入校验；`portableBackup` 只编排经验证的分区快照并提供事务回滚。`supportDiagnostics` 从计数和状态构建白名单诊断对象，UI 只负责预览、确认和下载。

## 任务

1. 为写作、计划和助手仓库补充经过校验的备份导入导出接口，并为阅读仓库增加无写入预检。
2. 先写完整学习备份的失败测试，再实现协议、预览、事务恢复和敏感配置排除。
3. 在成绩页实现完整备份下载、两阶段恢复和旧版阅读备份兼容。
4. 先写诊断隐私测试，再实现白名单诊断构建器和设置页下载界面。
5. 补充组件测试，证明预览确认、无效文件拦截和隐私文案。
6. 统一升级 0.9.8，更新 README、路线图、产品说明书和版本一致性测试。
7. 执行全量验证，构建 Windows 安装包，走查桌面界面和覆盖升级。
8. 按仓库规范提交、推送并发布 GitHub Release。
