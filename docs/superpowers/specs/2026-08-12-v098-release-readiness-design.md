# IELTS Pilot v0.9.8 发布就绪设计

## 目标

v0.9.8 解决换机、排障和升级验证三个发布前问题：用户能够一次导出并恢复完整学习数据；反馈更新或 AI 问题时能够导出不含学习正文和凭据的诊断文件；发布流程能够证明旧版可发现新版且覆盖安装后数据仍然存在。

## 范围

### 完整学习备份

- 新备份协议为 `ielts-pilot-portable-backup` v1。
- 包含阅读练习与题库、写作草稿与辅助报告、学习计划、AI 助手会话。
- 阅读偏好已属于阅读存储，因此随备份迁移。
- API Key、AI Endpoint、模型设置、同步令牌和远程同步配置明确排除。
- 导入分成“选择并校验”和“确认恢复”两步。预览显示四类数据数量以及来源版本。
- 所有分区必须先完整通过校验；任一分区无效时不写入。实际写入失败时用导入前快照回滚。
- 保留旧版阅读备份的兼容入口；旧文件仍可恢复阅读数据，但 UI 会说明它不包含写作、计划和会话。

### 隐私安全诊断

- 诊断文件只包含应用版本、运行方式、浏览器/系统标识、各数据分区数量、AI 是否可用、是否配置密钥以及存储健康状态。
- 不包含 API Key、Endpoint、作文正文、答案、题目内容、聊天正文、同步地址和代理地址。
- 设置页在导出前清楚列出“包含”和“不包含”的边界。
- 诊断协议为 `ielts-pilot-support-diagnostic` v1，便于后续支持工具读取。

### 升级与发布验证

- 版本统一升级至 0.9.8。
- 构建签名的 Tauri 更新产物和 NSIS Setup.exe。
- 验证 v0.9.7 能发现 v0.9.8；覆盖安装后验证应用版本和本地数据。
- README、路线图和产品说明书记录功能、限制、备份步骤与隐私边界。

## 不在本次范围

- 商业 Authenticode 代码签名证书。
- 真实第二台物理电脑和长期用户试用数据。
- PAC 脚本解释器、账号云同步和服务端遥测。

## 验收标准

1. 完整备份能在空存储中恢复四类数据，且不含任何 AI/同步敏感配置。
2. 损坏或部分无效的备份不会改变原数据。
3. 诊断 JSON 中不出现测试用密钥、Endpoint、作文、答案或对话文本。
4. 界面提供备份预览、明确确认和隐私说明。
5. 单元、集成、端到端、Rust 检查和生产构建通过。
6. Windows 桌面版完成演示数据、导出界面、诊断界面和更新状态截图。
