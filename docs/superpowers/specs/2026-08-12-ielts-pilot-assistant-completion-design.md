# IELTS Pilot 助手完整闭环设计

## 目标

在 0.9.5 的证据型助手基础上补齐严格验收中的剩余能力：可追踪的提示词版本、真实流式对话、自动执行判定与下一轮计划、周总结、写作任务与改写练习，以及可复现的 Windows 安装、升级、更新和真实 AI 走查。

## 已确认方案

用户已批准按“可靠性与发布闭环 → 对话体验 → 学习闭环 → 写作深化”的顺序直接实施。版本升级为 `0.9.6`，保持本地优先、悬浮球入口、三视图信息架构和现有编辑式视觉语言。

## 核心边界

- 助手提示词使用独立版本 `assistant-v2`，每条已验证回答记录版本、模型、请求号和 token 用量。
- Web 网关和 Tauri 都接收 provider SSE，逐增量显示原始安全文本；仅在完整 JSON 通过证据校验后才持久化结构化回答。
- 旧消息通过安全 Markdown 解析器渲染，不使用 `v-html`，链接只允许 `https`、`http` 和站内相对路径。
- 计划从新阅读尝试和写作报告自动判定执行状态；一轮完成后保留结果，并生成带新基线的下一轮任务。
- 写作快照只发送报告摘要、维度分数和问题统计，不发送作文正文或证据原句；原句仅在本地改写练习和报告深链中使用。
- API Key 继续由 Web 网关或 Windows DPAPI 持有，不进入浏览器存储、日志、回答、截图和 Git。

## 验收

1. 回答显示提示词版本、模型和上下文用量，回归集覆盖夸大结论、未知证据和越权路由。
2. 新练习或写作报告能自动完成对应行动并产生下一轮计划，周视图显示优先级、耗时和周总结。
3. Web 与 Tauri 都能看到可停止的真实增量输出；Markdown、重试、重生成、复制、删除和会话管理可用。
4. 助手显示写作摘要、维度变化、重复问题、报告证据深链、下一题和本地改写练习。
5. Windows DPAPI 保存/重启读取、真实桌面对话、异常映射、静默安装、覆盖升级、安装包、Release 和应用内更新全部有验证证据。

## 自查

范围没有账号、云端会话、后台提醒或官方评分声明。所有新状态均有明确来源和本地持久化边界，没有待定项。
