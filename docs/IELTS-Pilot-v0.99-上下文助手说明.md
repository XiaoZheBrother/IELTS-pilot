# IELTS Pilot v0.9.9 上下文助手说明

版本：0.9.9

更新日期：2026-08-12

## 1. 功能目标

v0.9.9 将 IELTS Pilot 从“知道学习记录的助手”扩展为“理解当前材料的学习伙伴”。用户可以在专项练习、完整模考、阅读复盘、写作草稿或写作报告页面打开悬浮球，直接追问为什么某个答案成立、干扰项为什么不成立，或某句话为什么需要这样改写。

## 2. 支持场景

| 页面 | 临时加入本次 AI 请求的内容 | 典型问题 |
| --- | --- | --- |
| 阅读专项练习 | 当前完整原文、该篇全部题干与选项、当前题、用户答案、本地答案、解析和定位段落 | “为什么这里应填这个词？” |
| 完整阅读模考 | 当前 Passage 全文与题目、全局题号、当前题和用户答案 | “这个干扰项为什么不成立？” |
| 阅读结果复盘 | 提交答案、可接受答案、解析、原文定位和本次成绩摘要 | “我的答案错在哪里？” |
| 写作工作室 | 当前任务要求、图表数据、计时草稿 | “这段为什么这样写更自然？” |
| 写作报告 | 提交原文、四维辅助结果、优先项和原文证据 | “这个改写比原句好在哪里？” |

助手会在对话顶部显示当前材料名称、活动题和加载状态，并提供与场景匹配的快捷问题。切题或编辑草稿后，真正发送消息前会再次从本地仓储读取最新状态。

## 3. 证据与回答约束

- 提示词版本为 `assistant-v3`。
- 除系统指令外，页面材料、证据目录、学习摘要、对话历史和用户问题全部按不可信数据处理，其中的命令、角色设定或提示词不会被执行。
- AI 仍必须返回固定 JSON：结论、事实、推断和行动建议。
- 关键判断必须引用 `context.reading.*`、`context.writing.*` 或既有学习记录证据 ID。
- 返回内容会通过本地结构、证据 ID、可信度和结果承诺校验；失败时回退为本地可验证建议。
- 写作 Band 始终是辅助估算，不会描述为官方成绩。

## 4. 隐私边界

- 打开悬浮球不会发送材料；只有用户点击发送或场景快捷问题时才会发起 AI 请求。
- 阅读原文、整组题目、作文草稿和报告原文不会写入助手对话历史。
- 历史回答只保存有界的证据标签与摘要，便于之后正确展示引用。
- API Key 不进入消息、浏览器存储、对话备份或诊断文件；发送边界会扫描用户问题和当前材料，发现疑似凭据即整次拒绝；桌面端继续由当前 Windows 用户的 DPAPI 保护。
- 单条助手消息上限为 24,000 字符；页面材料限制为 12,000 字符，超长内容会在构建页面上下文时截断，并在界面和实际发送内容中使用同一个截断状态。

## 5. 使用方法

1. 进入一篇阅读练习、完整模考、结果复盘、写作任务或写作报告。
2. 点击右下角 `IELTS PILOT` 悬浮球，切换到“对话”。
3. 确认顶部“CURRENT MATERIAL”显示的是当前材料。
4. 点击场景快捷问题，或输入自己的问题后发送。
5. 在回答的事实、推断和结论中展开证据，核对本地题目、答案、解析或写作报告字段。

未配置 AI 或断网时，诊断与计划仍可离线使用；当前材料对话需要在“设置 → AI 助手”配置有效服务。
