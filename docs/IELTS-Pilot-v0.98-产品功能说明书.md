# IELTS Pilot v0.9.8 产品功能说明书

版本：0.9.8
适用平台：浏览器、Windows 10/11 x64
定位：本地优先的 IELTS 阅读、写作与学习行动工作台

## 1. 版本目标

v0.9.8 把“可靠学习闭环”延伸到换机与排障。用户可以一次迁移阅读、写作、学习计划和助手会话；恢复前先看到经过校验的数据清单；遇到更新或 AI 连接问题时，可以导出一份不含学习正文、凭据和网络地址的白名单诊断文件。

## 2. 产品能力总览

### 阅读练习

- 5 篇原创英文文章、54 道题，前 3 篇组成 40 题完整模考。
- 覆盖单选、多选、T/F/NG、Y/N/NG、四种配对、简答及三种完成题。
- 专项练习、60 分钟模考、自动保存、暂停、标记、快捷键与移动端双面板。
- 本地规则评分、Academic Reading Band 练习估算、逐题解析和原文定位。
- 错题本、收藏、批注、强化练习、趋势、题型正确率和成绩历史。

### 题库与同步

- 内容包 v2 的字段校验、来源与许可预览、摘要校验、升级、冲突阻止和批量导入。
- 本地题库编辑器与 JSON 导出。
- PBKDF2 + AES-256-GCM 加密保险库、离线密文迁移和可选 ETag 同步。
- ECDSA P-256 签名内容目录、设备信任、密钥轮换阻止和原始包 SHA-256 校验。

### 写作与学习助手

- 原创 Academic Writing Task 1 / Task 2、字数、计时、草稿和历史报告。
- 四维结构化辅助 Band，程序独立复算总分，证据可回到原文；始终标注为非官方成绩。
- 悬浮式 IELTS Pilot 助手包含诊断、计划和对话，不占常驻侧边栏。
- 关键判断绑定本地证据 ID、样本门槛和可信度；证据不足的稳定性或提分保证会被程序拦截。
- 建议可直接进入相关练习或错题，记录基线并在练后比较；完成后生成下一轮任务。
- 支持真实流式输出、停止、重试、重新生成、复制、删除、安全 Markdown 和历史会话。

## 3. 完整学习备份

### 包含范围

完整备份协议标识为 `ielts-pilot-portable-backup`，当前协议版本为 1。一个文件包含：

- 阅读草稿、成绩、导入题库、本地题库草稿、阅读偏好、批注、收藏和错题掌握状态；
- 写作草稿和经过校验的辅助报告；
- 今日/本周学习计划、任务状态、基线与结果；
- 助手会话、结构化回答和可追溯元数据。

### 明确排除

- Windows DPAPI API Key 或任何明文凭据；
- AI Endpoint、模型设置；
- 同步令牌、同步地址、保险库口令；
- Windows 或应用代理地址。

这些配置都与设备或网络环境有关，换机后应在新电脑重新配置。

### 恢复流程

1. 在旧电脑进入“成绩 → 完整学习备份”，点击“导出完整备份”。
2. 把 JSON 文件复制到新电脑。
3. 在新电脑选择备份文件。
4. 核对来源版本和阅读、写作、计划、会话数量。
5. 点击“确认恢复”。确认之前应用不会写入任何数据。

应用先验证四个数据分区。任一分区损坏或版本不支持时，整个文件都会被拒绝；写入过程中发生本机存储错误时，会尝试恢复导入前快照。v0.9.7 及更早的纯阅读备份仍可导入，但界面会标记“旧版阅读备份”，不会误导为完整恢复。

## 4. 隐私安全诊断

“设置 → 支持与诊断”生成 `ielts-pilot-support-diagnostic` v1 JSON，使用固定字段白名单，只包含：

- 应用版本、浏览器或桌面运行方式、平台标识；
- 阅读成绩/草稿/题库包、写作草稿/报告、计划任务、会话/消息数量；
- AI 当前是否可用、桌面密钥是否已配置；
- 当前运行方式是否支持应用内更新。

诊断不会读取或附带 API Key、Endpoint、代理、同步地址、作文原文、用户答案、题目、报告正文或聊天内容。它适合在 GitHub Issue 或私下排障时提供，但发送前仍建议用户自行打开 JSON 复核。

## 5. 结构化 AI 与证据边界

- `assistant-v2` 固定返回结论、事实、推断和行动。
- 关键判断只能引用应用生成的稳定证据 ID；未知证据、外部 URL 和越权行动会被拒绝。
- 每项判断显示高可信、可参考或样本不足，并绑定样本数量。
- “成绩已稳定”“一定能提分”“官方成绩”等表述在证据不足或语义越界时会被拦截。
- 模型输出解析失败时不展示自由文本，而是回退到本地确定性建议。
- 回答保留提示词版本、模型、请求编号和 Token 用量，便于回归验证。

## 6. AI 配置与隐私

浏览器版通过同源本机网关调用，API Key 只存在于网关进程内存。Windows 桌面版通过 Rust HTTPS 命令调用，API Key 由 Windows 当前用户 DPAPI 加密后写入应用数据目录；只有同一 Windows 用户能够解密。

Endpoint 只允许 HTTPS，并拒绝 URL 中的用户名或密码。用户输入在保存和出站前检查常见凭据特征；疑似 API Key 不会保存也不会发送。助手只读取有界学习摘要，写作原文和证据句不会作为助手上下文发送。

## 7. Windows 安装与升级

从 GitHub Release 下载 `IELTS.Pilot_0.9.8_x64-setup.exe` 后直接运行。NSIS 安装器按当前用户安装，不需要管理员权限。覆盖旧版本会保留同一 Windows 用户的本地应用数据。

应用内“更新”页获取 GitHub Release 的 `latest.json`，并用内置 Tauri updater 公钥验证更新签名。v0.9.7 已支持读取安全的 Windows 当前用户直连代理；失败时会显示截断后的底层错误摘要，便于配合诊断文件排查。

当前开源构建没有商业 Authenticode 证书，因此 Windows SmartScreen 可能显示“未知发布者”。这不影响 Tauri updater 自身的强制签名验证；商业证书仍是正式大规模分发前的外部依赖。

## 8. 推荐走查

1. 在设置页安装固定演示档案。
2. 在成绩页检查 3 次阅读记录并导出完整备份。
3. 重新选择文件，核对四类数量预览，不立即确认。
4. 在设置页导出诊断，打开 JSON 确认不存在学习正文和网络地址。
5. 打开悬浮助手，检查证据型诊断、学习计划和真实流式对话。
6. 打开更新页，确认当前版本或可用新版本状态明确。

## 9. 验证范围

- TypeScript 类型检查、全量单元测试、网关/发布者集成测试、Playwright 桌面与移动视口走查、生产构建和 Rust 测试。
- 完整备份四分区往返、敏感配置排除、损坏文件无写入和旧版阅读备份兼容。
- 诊断字段白名单回归测试，测试密钥、Endpoint、作文、答案、对话和代理不得出现在 JSON。
- Windows NSIS 新装与覆盖安装、DPAPI 重启读取、签名 Release、旧版发现新版和更新元数据验证。

## 10. 已知边界

- 阅读与写作 Band 都是练习辅助估算，不是官方 IELTS 成绩。
- 没有商业 Authenticode 证书，也没有托管账号云服务。
- PAC 脚本解释、听力、词汇 SRS、口语评估和付费能力不在 v0.9.8 范围。
- 单机和自动化走查不能替代真实第二台物理电脑与 5–10 名用户的长期试用。
