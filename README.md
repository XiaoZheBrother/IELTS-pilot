# IELTS Pilot

一个面向雅思阅读自学的本地优先练习工作台。它提供从题库筛选、限时作答、自动保存，到本地评分、原文定位、错题复盘和学习统计的完整阅读闭环。

> 当前版本是独立练习工具，不是 IELTS 官方产品，也不提供官方成绩。

## v0.2 已实现

- 3 篇项目原创英文文章，共 40 道题，可组成一套 60 分钟完整阅读模考
- 12 种可渲染题型：单选、多选、T/F/NG、Y/N/NG、标题配对、信息配对、特征配对、句尾配对、简答、句子填空、摘要选词、图示填空
- 单篇专项练习与三篇完整模考两种模式
- 答案、当前位置、剩余时间和题目标记自动保存，刷新后可继续
- 40 题导航，可区分当前、已作答和已标记状态
- 本地即时评分、正确率和 Academic Reading Band 练习估算
- 每道题保存原文位置，结果页可展开对应段落和答案解析
- 可搜索、按难度和题型筛选的题库索引
- 带许可证、作者和来源校验的 JSON 内容包导入
- 最近五次趋势、题型正确率、学习时长和成绩历史
- 本地数据备份导出及恢复
- 桌面端和移动端响应式界面
- 单元测试、类型检查、生产构建和 Playwright 端到端测试

## 评分机制

当前评分不是外部 AI Skill，也不依赖大模型，而是一套可重复、可测试、可审计的本地规则：

1. 单选及配对题按选项键匹配。
2. 多选题将答案作为无序集合比较，并校验选择数量。
3. True / False / Not Given 与 Yes / No / Not Given 支持常见等价输入，例如 `T`、`YES`、`NG` 和 `not-given`。
4. 简答及完成类题目会统一大小写、空格、Unicode 形式和首尾标点，再与题目声明的可接受答案比对，同时检查单词数限制。
5. 单篇练习会按正确率折算为 40 题原始分；完整模考直接按 40 题计算，再使用项目内置的 Academic Reading 区间估算 Band。
6. 每份结果记录评分版本 `reading-v2`、题型、用户答案、可接受答案、解释及原文引用位置。

Band 只用于练习反馈，不能替代官方 IELTS 成绩。

## 内容包与版权边界

题库页可以导入声明式 JSON 内容包。导入器会检查：

- `schemaVersion` 必须为 `1`
- 内容包必须声明 `owner`、`license`、`note`，并建议提供 `sourceUrl`
- 练习和题目 ID 不可重复
- 题型必须属于当前支持范围
- 每道题的 `sourceRef` 必须指向存在的段落
- 拒绝包含 `<script>` 的内容

导入功能不代表项目方授予任何第三方内容使用权。请只导入原创、公共领域或已获得明确授权的材料；使用者需要自行确认许可证允许修改、再分发和目标使用方式。

## 本地运行

环境要求：Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址即可。应用当前不需要后端或数据库，练习草稿、成绩和导入内容保存在当前浏览器的 `localStorage` 中。

## 验证

```bash
# 单元测试
npm run test:unit

# 类型检查、单元测试与生产构建
npm run check

# 首次运行 E2E 前安装 Chromium
npx playwright install chromium
npm run test:e2e
```

## 技术结构

```text
src/
├── components/     # 题目控件、练习索引与原文复盘
├── composables/    # 专项练习、完整模考、倒计时和自动保存
├── data/           # 原创文章、40 道题和完整模考定义
├── domain/         # 题型模型、答案匹配、评分、分析和内容校验
├── storage/        # v1 迁移、v2 本地仓储及备份
├── styles/         # 设计变量、页面壳、作答台和报告样式
└── views/          # 工作台、题库、模考、结果和统计页面
```

技术栈：Vue 3、TypeScript、Vite、Vue Router、Vitest、Vue Test Utils、Playwright。
