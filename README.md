# IELTS Pilot

一个面向雅思阅读自学的本地优先练习 MVP。它不只显示“对或错”，还会保留作答进度、给出可审计的逐题评分，并把每道题的参考答案和判断依据展示出来。

> 当前版本为独立练习工具，不是 IELTS 官方产品，也不提供官方成绩。

## MVP 已实现

- 2 套项目原创英文阅读材料，共 16 道题
- 单项选择、True / False / Not Given、简短回答三种题型
- 25 分钟倒计时与到时自动提交
- 答案、题目位置和剩余时间自动保存，刷新后可继续
- 本地即时评分、正确率和 Academic Reading Band 练习估算
- 逐题展示你的答案、参考答案和解释
- 浏览器本地成绩历史，可重新打开结果
- 桌面端和移动端响应式界面
- 单元测试与 Playwright 端到端测试

## 评分机制

当前评分不是外部 AI Skill，也不依赖大模型，而是一套可重复、可测试的本地规则：

1. 选择题按选项键精确匹配。
2. True / False / Not Given 支持 `T`、`YES`、`NG`、`not-given` 等常见输入别名。
3. 简短回答会统一大小写、空格和首尾标点，再与题目声明的可接受答案比对，同时检查单词数限制。
4. 短套题正确率会先折算为 40 题原始分，再根据项目内置的 Academic Reading 对照区间估算 Band。
5. 每份结果记录评分版本 `reading-v1`，并保存逐题判定，便于后续审计和升级。

Band 仅用于练习反馈。短套题样本较少，不能替代完整模考或官方 IELTS 成绩。

## 本地运行

环境要求：Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址即可。应用不需要后端或数据库，练习草稿与成绩保存在当前浏览器的 `localStorage` 中。

## 验证

```bash
# 单元测试
npm run test:unit

# 类型检查与生产构建
npm run check

# 首次运行 E2E 前安装 Chromium
npx playwright install chromium
npm run test:e2e
```

## 技术结构

```text
src/
├── components/     # 题目、练习卡片与分数展示
├── composables/    # 倒计时、自动保存和提交会话
├── data/           # 原创练习材料及题目
├── domain/         # 答案匹配、评分规则和领域类型
├── storage/        # versioned localStorage 仓储
└── views/          # 练习桌、作答页与结果复盘页
```

技术栈：Vue 3、TypeScript、Vite、Vue Router、Vitest、Vue Test Utils、Playwright。
